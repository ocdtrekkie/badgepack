# Badgepack

Badgepack is an OpenBadges backpack for Sandstorm. Hold proofs of your accomplishments in a centralized self-hosted library.

Note that Badgepack does not have web access, and therefore support for OpenBadges 2.0 badges is quite limited. Most OpenBadges 3.0 badges should work well though.
